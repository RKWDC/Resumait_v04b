# **App Name**: Refraction Resumate

## Core Features:

- Resume Upload/Paste: Allows users to upload a resume (PDF, DOC, DOCX, TXT) or paste the text into a form.
- Job Description Upload/Paste: Enables users to upload a job description file or paste the job description text into a field.
- ATS Resume Optimization: Leverages AI to rewrite the resume, tailoring it to the job description while ensuring ATS compatibility. This feature incorporates the 'tool' concept, reasoning about which details to include based on relevance.
- Optional Cover Letter Generation: Generates a tailored cover letter based on the job description and resume content.
- Output Display and Copy/Download: Presents the optimized resume and cover letter (if selected) in a clean format, with options to copy to clipboard or download as TXT or DOCX.
- Progress Indicator: Shows a progress indicator during the resume analysis and optimization process.
- Error Handling: Gracefully handles unsupported file types and other errors with clear user-facing messages.

## Style Guidelines:

- Primary color: Black (#000000) to convey trustworthiness and professionalism.
- Background color: White (#FFFFFF) to provide a clean, non-distracting backdrop.
- Accent color: Red (#FF0033) to draw attention to key actions and elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern, objective, neutral look suitable for both headlines and body text.
- Use clean, simple icons to represent actions like upload, download, and copy. The style should be consistent with the overall minimalist design.
- Maintain a clean and responsive layout. Use a single-column layout for mobile devices and a multi-column layout for larger screens.
- Incorporate subtle animations for feedback, such as a progress bar filling during analysis or a brief highlight when copying text.
